subparsers:
a parser associated with a subcommand of a parent command  
ex command:python tool.py add "Study Python"-> here add selects a subcommand that subcommand can have its own argument
code ex:
import argparse
# 1. Create the main parser,ie parent parser 
parser = argparse.ArgumentParser(
    description="A task management utility")
# 2. Enable subcommands(collects subparsers) creates mechanism for sub commands
subparsers = parser.add_subparsers(dest="command", required=True)# dest is just a name for where the sub commands are stored 
# 3. Define the add command
add_parser = subparsers.add_parser("add")
add_parser.add_argument(
    "description",
    help="Description of the task")
# 4. Define the list command
list_parser = subparsers.add_parser("list")
# 5. Define the remove command
remove_parser = subparsers.add_parser("remove")
remove_parser.add_argument(
    "task_id",
    type=int,
    help="ID of the task")
# 6. Parse the command-line arguments
args = parser.parse_args()
# 7. Execute the selected operation
if args.command == "add":
    print(f"Adding task: {args.description}")
elif args.command == "list":
    print("Listing tasks...")
elif args.command == "remove":
    print(f"Removing task: {args.task_id}")

walrus operator
syntax 
:=
it is a small feature but makes code much cleaner 
it lets you assign a value to a variable inside an expression 
you cannot assign value in an expression in python 
like 
a = False
print(a=True) this will rais a syntax error 
but insted of using assignment operator if we use walrus operator we can assign a value inside of an expression
print(a:=True) this will work this will change the orignal value too 
not just here it will work in many complex situations and make our operations much easier and clean and readable 

for ex:
without walrus operator 
while True:
    text = input("Enter something (or 'quit'): ")
    if text == "quit":
        break
    print(text)
	
but using walrus operator you can cut it down to
while(text :=input("enter something or quit"))!=quit:
	print(text)
you see 5 lines of code cut down to 2 lines

it performs high level file operations copies moves directries and files it is different from os, win32file, open()

os intercts with os directly to operate on directries

requests module 
it is library that allows python programs to authenticate, sessions, headers, timeouts, and error handeling
when a client sends a request to a server, it uses HTTP methods or HTTP verbs to indicate the desaired action it wants the server to perform on a resource 
the primary requests are:
GET  -> asks server to send back a representation of a specific resource
POST -> sends data to a server to create a new resource 
PUT  -> sends data to update an entair existing resource, or create if it doesn't already exist 
PATCH-> applies partial modification to a resource 
DELETE-> requests the server to remove the specific resource

secondary requests:
HEAD -> identical to get request but server returns only the headers without the response body
OPTIONS -> asks the server what communication options or HTTP methods are available
TRACE -> performs a loop back test along the path to the target resource 
CONNECT -> establishs a tunnel to the server identified by the target resource 

requests module helps the program handle https or http request to the server 
starting with get request:
response = requests.get("https://jsonplaceholder.typicode.com/post/1")

http status codes :
| Status code                 | Meaning                              |
| --------------------------- | ------------------------------------ |
| `200 OK`                    | Request succeeded                    |
| `201 Created`               | Resource created successfully        |
| `400 Bad Request`           | Request was invalid                  |
| `401 Unauthorized`          | Authentication is missing or invalid |
| `403 Forbidden`             | Server refuses the operation         |
| `404 Not Found`             | Resource not found                   |
| `429 Too Many Requests`     | Too many requests were made          |
| `500 Internal Server Error` | Server encountered an error          |

lets understand the response object 
when we execute requests.get(....) it returns an object containing several attributes 
| Attribute or method           | Purpose                                        |
| ----------------------------- | ---------------------------------------------- |
| `response.status_code`        | HTTP status code                               |
| `response.text`               | Response body as text                          |
| `response.content`            | Response body as bytes (useful when need to parse images)|
| `response.json()`             | Decode a JSON response                         |
| `response.headers`            | Response headers                               |
| `response.url`                | Final URL of the response                      |
| `response.encoding`           | Text encoding used to decode the body          |
| `response.raise_for_status()` | Raise an exception for HTTP error status codes |

suppose you are making 100s of requests we can just use directly but using session is more convenient for reuse of the resources
with requests.Session() as session:
    response1 = session.get(
        "https://jsonplaceholder.typicode.com/posts/1",
        timeout=10
    )
    response2 = session.get(
        "https://jsonplaceholder.typicode.com/posts/2",
        timeout=10
    )
    print(response1.status_code)
    print(response2.status_code)
